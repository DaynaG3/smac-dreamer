Defects found and corrected during audit
----------------------------------------
1. Replay initially stored only post-action carry age. Starting imagination
   from that state would evaluate termination twice at the same posterior.
   Added explicit pre-decision replay fields and a regression test.

2. The first design kept ordinary Dreamer actor/value losses alongside the
   hierarchy, training the same value network toward two different behaviour
   policies. Hierarchy mode now removes policy/value/repval from the base
   loss before total-loss construction.

3. Copying the highly confident two-way v1.2 selector at full scale would
   starve options 2--7. The manager hidden representation is retained while
   the output is temperature-softened and new rows start near neutral.

4. Termination entropy/collapse regularizers originally remained active during
   the fixed-hazard warm-up. They are now multiplied by the same activation
   blend, making the learned termination head exactly frozen through 100k.

5. Diversity pair rotation originally depended on replay count, which caps at
   buffer capacity. It now uses a checkpointed per-update counter so all pairs
   continue rotating throughout training.

6. A hierarchy-value log-probability shape mismatch was found by the synthetic
   end-to-end gradient test and fixed before packaging.

7. Real replay option metrics were added separately from imagined metrics so
   dwell/boundary/termination behaviour can be diagnosed directly.
