Scope
-----
The bundle installs both requested mechanisms together:
1. automatic adaptive map collection from critic-error statistics;
2. recurrent candidate-pool sequence PER with importance-sampling correction.

Sanity-check corrections included
---------------------------------
- Resume progress no longer derives solely from the newly empty replay buffer.
- A trusted absolute-step override is available because old checkpoint step values
  could be bounded by replay capacity.
- Replay refill, not restored absolute progress, gates the first learner update.
- Priority error compares replay return targets with the current trainable critic,
  not the frozen/slow critic used for stable targets.
- Importance-sampling weights apply to JEPA replay losses and imagined actor/critic
  starts; map feedback is also IS-weighted to avoid compounding replay bias.
- Map feedback uses per-timestep log_map_id, so a recurrent window that crosses an
  episode/map boundary updates each map separately.
- Equal map statistics receive equal ranks; initial tied/unseen maps remain uniform.
- Held-out evaluation workers never receive adaptive probabilities or feedback.
- Python, NumPy, Torch, CUDA RNG, optimizer/scheduler/scaler state, absolute step,
  and adaptive map state are handled on checkpoint continuation.
- Sequence-priority cache is not restored without the exact matching replay.
- Adaptive worker recycling uses a generation-specific sampler seed.
- The generated YAML is derived from the exact source YAML and the preflight
  requires validation.every == 200000.
