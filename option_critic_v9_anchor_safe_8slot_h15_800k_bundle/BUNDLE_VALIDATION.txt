Option-Critic v9 anchor-safe eight-slot H=15 / 800k validation
================================================================

Supersession
------------
Do not use v7 or v8.

The final v8 re-audit found these additional defects/design hazards:
- critical: the no-grad hierarchy used by real acting and imagination was a
  non-aliased step-zero snapshot, so optimizer updates to the live slot manager
  and child worker were not executed;
- the Exp45 installer was invoked without the real workspace ROOT and could
  install under the root user's HOME;
- the initial within-group prior placed 75% of collection on unproven children;
- child output and worker loss used the same warm-up factor, accidentally
  squaring the effective ramp;
- option critics could split identical child values through identity-specific
  Monte-Carlo noise before children had causal action differences;
- worker trust-region diagnostics could leave tiny floating-point gradients at
  exact source equality during the intended critic-only warm-up;
- runtime assertions could combine stale values from old metric rows with the
  current global step;
- the launcher did not fail closed on the exact source checkpoint hash;
- a failed forecast wrapper could leave a GPU child alive before RL launch.

v9 corrections
--------------
- The online no-grad hierarchy view intentionally shares live parameter storage,
  matching R2-Dreamer's actor/world-model frozen-view semantics.
- The permanent source reference remains a true non-aliased deep copy.
- All eight identities are active with a 40% conditional anchor floor; the
  zero-logit prior is approximately 54.7/15.1/15.1/15.1 per source group.
- Child action scale is fixed and bounded; worker PG is the sole learning ramp.
- Child option values are tied to the detached anchor during worker warm-up and
  the consistency term decays to zero as child policies become causal.
- Worker trust-region objectives are absent from the graph when worker PG is
  exactly zero.
- Runtime assertions track each metric's own most recent step and reject stale
  values.
- Forecast installation propagates ROOT and verifies all required installed
  files.
- The master pipeline refuses concurrent RL when an Exp45 child remains active.
- The RL launcher enforces the exact Tactical-v1.2 best-checkpoint SHA-256 and
  resets the fresh phase to step zero.
